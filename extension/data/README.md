# Dictionary data

`cedict_ts.u8` is **CC-CEDICT**, a community-maintained Chinese-English
dictionary published by MDBG. It is distributed here unmodified.

The file's header records its publication date and entry count. To refresh it,
run `npm run update-dict` from the repository root.
